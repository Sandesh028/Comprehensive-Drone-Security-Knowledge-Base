OWASP Drone Top 10

Ten risk classes for UAS, each with a real example, mitigations, and a link into the taxonomy. Filter by severity.

D01CRITICAL

Insecure Communication

MAVLink / OcuSync / RF downlink

Control and telemetry links transmitted without confidentiality or integrity, allowing interception, modification, or injection of commands and video.

SEEN IN MAVLink sends unencrypted messages by default; DJI DroneID broadcasts unencrypted pilot location (NDSS 2023).

Mitigations & mapping
  • MAVLink 2.0 message signing
  • AES-256 / ChaCha20 link encryption
  • DTLS tunneling
  • Encrypted RF links (e.g. OcuSync)

D02CRITICAL

Weak Authentication & Authorization

Wi-Fi / Bluetooth / Telnet

Default credentials, missing authentication, or exposed debug services that allow unauthorized control of the airframe or its services.

SEEN IN Unauthenticated Telnet root on consumer UAVs (CVE-2024-6422); Holy Stone Remote ID unauthenticated power-off (CVE-2024-52876).

Mitigations & mapping
  • WPA3-SAE
  • Certificate-based auth
  • X25519 key exchange
  • Disable default/debug services in production

D03HIGH

Insecure Firmware & Software

JTAG / SWD / ADB / DUML

Memory-corruption bugs, unsigned updates, and exposed debug interfaces enabling persistent compromise.

SEEN IN DJI Mavic 3 vtwo_sdk memory corruption via DUML fuzzing (CVE-2023-51454/55/56, NDSS 2023).

Mitigations & mapping
  • Secure boot chain
  • Signed firmware with rollback protection
  • Disable debug ports
  • Memory-safe parsing of control protocols

D04HIGH

GPS / GNSS Spoofing

GPS L1 / L5

Civil GNSS signals are unencrypted and weak (~-130 dBm) and can be overpowered to mislead navigation.

SEEN IN UT Austin demonstrated capture of a civilian UAV via GPS spoofing; consumer airframes remain broadly susceptible.

Mitigations & mapping
  • Multi-constellation receivers
  • Spoofing-aware RAIM
  • Inertial cross-checks
  • Signal-authentication GNSS (e.g. Galileo OSNMA)

D05HIGH

Insufficient Network Security

Wi-Fi AP / onboard services

Onboard network services (FTP, Telnet, RTSP, debug HTTP) exposed without hardening.

SEEN IN Open RTSP video and Telnet on the airframe AP (see CVE-2024-6422).

Mitigations & mapping
  • Close unused ports
  • Authenticate every service
  • Network segmentation onboard
  • Egress filtering

D06MEDIUM

Inadequate Data Protection

Onboard storage / logs / media

Flight logs, media, and configuration stored or transmitted without encryption.

SEEN IN Recoverable flight logs and media after unauthenticated shell access.

Mitigations & mapping
  • Encrypt data at rest
  • Strip metadata on export
  • Secure-erase on decommission

D07MEDIUM

Lack of Secure Update Mechanism

OTA / app-assisted update

Updates delivered without signature verification or downgrade protection.

SEEN IN Firmware downgrade to a vulnerable build to re-enable a patched flaw.

Mitigations & mapping
  • Signed updates
  • Monotonic version / anti-rollback
  • TLS-pinned update channel

D08MEDIUM

Insecure Third-Party Components

SDKs / OSS dependencies

Vulnerable SDKs, libraries, or RF modules inherited into the airframe.

SEEN IN Vulnerable Remote ID modules sourced across vendors (CVE-2024-52876).

Mitigations & mapping
  • SBOM for airframe + GCS
  • Pin and monitor dependencies
  • Vet RF/Remote ID modules

D09MEDIUM

Physical & Remote ID Weaknesses

Debug headers / Remote ID broadcast

Accessible debug headers and spoofable or DoS-able Remote ID broadcasts.

SEEN IN Remote ID power-off via BLE (CVE-2024-52876); spoofable Open Drone ID broadcasts.

Mitigations & mapping
  • Remove/lock debug headers
  • Authenticate Remote ID where feasible
  • Tamper-evident enclosures

D10LOW

Insufficient Logging & Monitoring

GCS / fleet telemetry

No tamper-evident logging of control events, making intrusions and spoofing invisible after the fact.

SEEN IN Spoofing and command injection leave no airframe-side record.

Mitigations & mapping
  • Signed flight-event logs
  • GCS-side anomaly detection
  • Fleet telemetry baselining

DEFENDER CONTENT · 4 SIGNATURES

Detection Signatures

Shippable Suricata, Zeek, and YARA content that detects the documented exposures. Tune SIDs and thresholds for your environment.

SuricataInitial Access

Unauthenticated Telnet on airframe network

Flags a successful Telnet negotiation reaching a BusyBox/root banner on the drone AP subnet.

alert tcp any any -> $HOME_NET 23 (msg:"UAS unauthenticated Telnet root banner"; flow:established,to_client; content:"BusyBox"; nocase; content:"built-in shell"; distance:0; classtype:attempted-admin; sid:9000001; rev:1;)

SuricataReconnaissance

Exposed RTSP video stream on airframe

Flags unauthenticated RTSP DESCRIBE on the drone subnet (open video feed enumeration).

alert tcp any any -> $HOME_NET 554 (msg:"UAS open RTSP DESCRIBE (no auth)"; flow:established,to_server; content:"DESCRIBE rtsp://"; nocase; content:!"Authorization:"; classtype:attempted-recon; sid:9000002; rev:1;)

ZeekImpact

Remote ID broadcast flood / spoofing

Zeek script sketch: alert when Open Drone ID basic-ID messages exceed a per-second threshold from one source, indicating spoof flooding.

# zeek (sketch)
event odid_basic_id(src: string, count: count) {
    if ( count > 50 )
        NOTICE([$note=UAS::RemoteID_Flood, $msg=fmt("Remote ID flood from %s", src)]);
}
